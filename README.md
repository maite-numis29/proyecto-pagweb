# 🌿 Vivero Marino - Tienda Online

Sitio web e-commerce maquetado para **Vivero Marino**, especializado en la venta de plantas, macetas, sustratos y herramientas de jardinería. Proyecto desarrollado como entrega integradora para el curso de Desarrollo Web de **TalentoTech**.

## 🚀 Características del Proyecto

* **Encabezado y Navegación:**
  * Logo de la marca e integraciones visuales.
  * Barra de búsqueda interactiva y acceso al carrito de compras.
  * Menú de navegación principal y categorías.

* **Sección Hero / Banner Promocional:**
  * Banner de bienvenida a la temporada con botón de llamada a la acción (*CTA*).

* **Catálogo de Productos:**
  * Grilla responsiva (*CSS Grid/Flexbox*) con tarjetas de productos (Macetas, Suculentas, Abonos, Herramientas, etc.).
  * Detalles de productos: etiqueta, descripción, precio y botón "Agregar al carrito".

* **Ubicación y Contacto:**
  * Sección de información de contacto con dirección local en Francisco Álvarez, Moreno.
  * Mapa interactivo integrado mediante Google Maps (`iframe`).
  * Enlaces directos a redes sociales (Facebook, Instagram, WhatsApp) e email.
  * Formulario funcional de contacto integrado con **Formspree**.

* **Pie de Página (Footer):**
  * Estructura en columnas con información sobre la tienda, datos de contacto y redes sociales con iconos de Font Awesome.

---

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Maquetación semántica y accesible.
* **CSS3:** Estilos personalizados, diseño responsivo, Flexbox y CSS Grid.
* **Font Awesome (v6.5.2):** Iconografía para redes, navegación y botones.
* **Formspree:** Procesamiento del formulario de contacto.
